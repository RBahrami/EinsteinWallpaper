Einstein hat & 13 tiling families

Canvas
Layers

Click a layer to edit it in the sections below. The Background layer is pinned to the bottom — it cannot be deleted or reordered. Every pattern layer keeps its own tiling, colors, effects and animation; exports render the whole stack.

Tiling
Color theme

Every mode keeps its own arrangement, editor and templates; edits apply to the selected layer live. Auto outline picks a border color from the palette/background; uncheck it to set a manual border color. The wallpaper background lives on the Background layer (see the Layers section). Saved templates and custom palettes/gradients persist in the browser and travel with the theme export/import files.

Background layer

The Background layer is always at the bottom of the stack. It supports a solid color or a fully editable gradient (type, angle, stops) and never depends on the selected pattern layer. Hide it (eye icon in Layers) or set opacity below 100% to export PNG/APNG wallpapers with real transparency.

Project file

Downloads/loads the whole project (all layers, settings and custom palettes/gradients) as one JSON file. The format is documented in docs/AGENT_GUIDE.md — agents can generate wallpapers by producing that JSON and loading it here.

Visual effects

Effects apply to the selected layer only — in the live preview and in every export format alike. 0 = off.

Animation

Each layer animates independently on a shared timeline. Animated exports align every layer to one seamless loop.

Export & live wallpaper

Exports always render the complete layer stack at the canvas resolution chosen above — no third-party software or codec needed to play them. PNG/APNG keep true RGBA transparency when the Background layer is hidden or faded; GIF has no partial alpha, so transparent projects are flattened onto black. GIF is compact (256 colors + dithering); APNG is pixel-perfect lossless truecolor. Windows: install Lively Wallpaper (free) → Add Wallpaper → paste this page's URL as a web wallpaper, or drop the exported GIF/APNG in as a video wallpaper.
Android: set the exported GIF/APNG with any “video live wallpaper” app, or use Wallpaper Engine.

About

A studio for the aperiodic Einstein hat monotile (Smith, Myers, Kaplan & Goodman-Strauss 2023 — An Aperiodic Monotile, arXiv:2303.10798) plus a collection of mathematically verified periodic and composite tilings: honeycombs, kagome, octagon–square, Cairo pentagons (dual of the snub square tiling), herringbone, Penrose rhombs (dual of a de Bruijn pentagrid) and more.
